# Quiz Palito — pedidos prontos (para gastar menos do plano)

**Regra de ouro:** uma **conversa nova para cada tarefa**. Eu lembro de tudo pela memória (pastas, voz, estilo, Chrome, canais), então não precisa continuar na mesma conversa.

**Modelo:** para postar, responder comentários e conferir coisas, use o **Sonnet**. Deixe o **Opus** para criar vídeo novo.

**Antes de pedir algo no navegador:** Chrome do perfil **Quiz** aberto, logado no **Quiz Palito**, com a aba na frente (não minimizado).

---

## Fazer um vídeo novo a partir de uma referência
```
Assiste esse vídeo (leve, só transcrição e poucos quadros) e faz a versão Quiz Palito: <LINK>
Faz o vídeo longo + kit do YouTube + 1 Short com movimento. Não posta, me avisa quando terminar.
```

## Fazer só um Short
```
Faz um Short com movimento sobre <TEMA>, 6 perguntas, mesmo padrão do Short de português. Não posta.
```

## Agendar a produção para outro horário
```
Agenda para <DIA> às <HORA>: <o mesmo pedido de vídeo acima>
```

## Postar o que está pronto
```
Posta no YouTube e no TikTok o <NOME DO VÍDEO/SHORT> que está pronto em <PASTA>. Pode publicar.
```
(Com "Pode publicar" no pedido, eu já publico sem perguntar de novo.)

## Comentários
```
Lê os comentários sem resposta do YouTube, escreve respostas no tom do Palito e posta.
```
(A checagem automática roda todo dia às 19h e só sugere; se quiser que poste direto, diga.)

## Conferir resultados
```
Como estão as visualizações e inscritos do Quiz Palito hoje?
```

---

## Dicas que economizam
- Junte tudo num pedido só ("faz e posta nos dois") em vez de vários "pronto".
- Se o Chrome pedir login ou travar, resolva você e mande "pronto" uma vez só.
- Vídeos grandes rodam em sessão separada (agendada): mais barato do que fazer aqui conversando.
